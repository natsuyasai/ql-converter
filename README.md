# ql-converter — ファイル → QRコード転送

PC上の小さなファイル(数十KB程度)を、QRコードを介してスマホに転送するツールです。
サーバー・ケーブル・専用アプリは不要で、データは端末の外に出ません。

```
PC: ファイル → 圧縮 → 分割 → QRコード(A4のPNG、複数ページ可)
スマホ: 受信ページでQRをカメラ読み取り(順不同OK) → 復元 → 保存
```

## 使い方

### 1. 送信(PC)

**ブラウザ版**: `index.html` を開き、ファイルをドロップ(またはクリックで選択)。
QR画像がページごとに表示されるので、画面に表示するか「PNG保存」して印刷します。

**Node.js CLI**(Node 20+):

```bash
npm install
node cli/make-qr.mjs <file> [-o out.png] [--ec M] [--chunk 600] [--per-page 12]
```

QRが1ページに収まれば `out.png`、複数ページなら `out-1.png`, `out-2.png` … を出力します。
出力先を省略すると `<ファイル名>.qr.png` になります。

### 2. 受信(スマホ)

`receive.html` をスマホのブラウザで開き、「カメラ開始」を押してQRに順にカメラを向けます。

- 順番は自由です。読み取り済みのQRを重ねて読んでも問題ありません
- 進捗(何枚中何枚)と未取得の番号が表示されます
- 全部そろうとハッシュ検証を行い、一致したときだけ「ダウンロード」できます
- 別のファイルのQRや無関係なQRは無視されます(別ファイルに切り替えるときは「やり直し」)
- カメラが使えないときは、QRの画像ファイルから読み取ることもできます

カメラの利用には **HTTPS**(または `localhost`)が必要です。GitHub Pagesはそのまま対応しています。

## GitHub Pagesで公開する

1. このリポジトリをGitHubにpushする
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして保存
3. `https://<ユーザー名>.github.io/<リポジトリ名>/`(送信)と `.../receive.html`(受信)を開く

`vendor/` は依存ライブラリを同梱したものです(CDN不使用)。ビルド工程はありません。
依存を更新したときだけ `npm install && npm run vendor` で作り直してください。

## 制限と目安

- 入力は **256KBまで**(超えるとエラー)。64KB以上は警告(QRが多くなります)
- 1QRあたり約600文字、1ページ最大12枚(いずれも調整可)
- 枚数の実測(乱数=圧縮できない場合 / 12枚ごとに1ページ):

  | ファイルサイズ | 乱数・既存zipなど | テキストなど圧縮が効く場合 |
  |---|---|---|
  | 5KB | 12枚 (1ページ) | — |
  | 10KB | 23枚 (2ページ) | — |
  | 20KB | 46枚 (4ページ) | 12枚 (約1ページ) |
  | 30KB | 69枚 (6ページ) | — |
  | 50KB | 114枚 (10ページ) | 24枚 (約2ページ) |

- QRは1枚ずつ読み取ります(ページ全体を一度に撮影しても、全QRは読み取れません)
- 暗号化・誤り訂正符号(QR間)はありません

## 開発

```bash
npm test                    # 自動テスト(プロトコル、レイアウト、CLIのPNG往復)
node scripts/serve.mjs 8080 # ローカル確認用の静的サーバー(http://localhost:8080/)
```

構成: `src/`(プロトコル・QR・レイアウトの共通コア)、`cli/`(Node CLI)、
`index.html` + `web/send.mjs`(送信ページ)、`receive.html` + `web/receive.mjs`(受信ページ)。

設計書と実装計画: `docs/superpowers/`
